# MCP Workbench

Use the controls in the chat settings panel to choose a model, prompt profile, and MCP server for this session.

For OpenAI-compatible providers, set `LLM_API_KEY` before sending messages. For Vertex AI, set `LLM_PROVIDER=vertex_ai`, `VERTEX_AI_PROJECT`, and either `VERTEX_AI_CREDENTIALS_PATH` or Application Default Credentials.
